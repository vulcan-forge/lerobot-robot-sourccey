# Sourccey documentation

The guides are separated by task so operators do not need to search through a
single large README.

1. [Setup](01-setup/README.md) — install software, start the host, and find the
   optional provisioning and calibration procedures.
2. [Control systems](02-control-systems/README.md) — teleoperate, record, replay,
   and deploy policies.
3. [SDK](03-sdk/README.md) — use the Python helpers, cameras, movement commands,
   and 2D LiDAR tools.
4. [AI and datasets](04-ai/README.md) — manage datasets and train policies.

Return to the [package overview](../README.md).

[Policy rollout and desktop shutdown](rollout.md) describes package-owned stop
control, missing-arm policy inputs, and calibration recovery.

[LeRobot workspace quickstart](lerobot-workspace/README.md) provides an ordered
controller-and-robot setup, teleoperation, recording, replay, training, and
rollout walkthrough, plus hardware checks and troubleshooting. Run its
commands from the LeRobot workspace as described in the guide.
