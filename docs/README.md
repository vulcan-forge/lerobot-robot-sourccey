# Sourccey documentation

The guides are separated by task so operators do not need to search through a
single large README.

1. [Python SDK](sdk.md) — connect from Python, read observations and cameras,
   and issue validated base and lift commands.
2. [Setup](setup/README.md) — install software, prepare hardware, calibrate the
   robot, start the host, and maintain the package.
3. [Control systems](control-systems/README.md) — teleoperate, record, replay,
   and deploy policies.
4. [AI and datasets](ai/README.md) — manage datasets and train policies.
