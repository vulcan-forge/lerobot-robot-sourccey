# Robot setup

For a factory-prepared Sourccey, use the normal path:

1. [Install](01-install.md) — install the robot package profile.
2. [Robot host](05-host.md) — start the service used by the controller.

The following procedures are not required during normal installation:

- [Robot devices](02-devices.md) — provision or verify Linux device aliases on
  a fresh or repaired computer.
- [Battery](03-battery.md) — inspect or recover the battery gauge.
- [Calibration](04-calibrate.md) — restore packaged ranges or redetect physical
  limits after hardware service.

Return to the [setup index](../README.md).
