# Robot setup

Prepare Sourccey's Linux computer in this order:

1. [Install](01-install.md) — install the robot package profile.
2. [Robot devices](02-devices.md) — verify stable sensor and actuator names.
3. [Battery](03-battery.md) — inspect or configure the battery gauge.
4. [Calibrate](04-calibrate.md) — calibrate the arms and Z actuator.
5. [Robot host](05-host.md) — start the service used by the controller.

Return to the [setup index](../README.md).
