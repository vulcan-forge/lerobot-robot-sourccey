# Robot setup

Prepare Sourccey's Linux computer in this order:

1. [Install](install.md) — install the robot package profile.
2. [Robot devices](devices.md) — configure stable arm and camera device names.
3. [Battery](battery.md) — inspect or configure the battery gauge.
4. [Calibrate](calibrate.md) — calibrate the arms and Z actuator.
5. [Robot host](host.md) — start the service used by the controller.

Return to the [setup index](../README.md).
